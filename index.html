03 • ВИДЕО

Видео — главный тяжёлый ресурс

Поэтому на первом этапе устанавливаем максимальную длину короткого ролика — 30 секунд. Это позволяет контролировать хранение, обработку и передачу данных.

30 сек.

Ограничение ролика

Меньше средний размер файла — предсказуемее инфраструктурные расходы.

CDN

Быстрая доставка

Популярный контент отдаётся через кэш и CDN, а не через основной backend.

Storage

Отдельное хранение

Видео хранится отдельно от базы и серверов бизнес-логики.

Главный принцип: приложение-сервер не должен становиться «видеохранилищем». Тяжёлые данные выносятся в отдельный контур.

15 • ЭКОНОМИЯ НА ИНФРАСТРУКТУРЕ

Как не превратить видео в дыру бюджета?

1. 30 секунд

Ограничиваем размер короткого ролика.

2. Compression

Автоматически уменьшаем размер видео после загрузки.

3. CDN

Повторные просмотры отдаём через кэшированную сеть.

4. Object Storage

Медиа отделяется от application-серверов.

5. Redis

Горячие данные не приходится постоянно брать из базы.

6. Автомасштабирование

Дополнительные мощности включаются по мере роста нагрузки.

16 • 100 000 АКТИВНЫХ ПОЛЬЗОВАТЕЛЕЙ

Ориентировочная инфраструктура

Это модель для оценки порядка расходов. Фактическая стоимость зависит прежде всего от видеопросмотров, трафика, хранения и выбранных поставщиков.

Статья Ориентир / месяц Что влияет
Backend / API 60–140 тыс. ₽ Запросы и количество узлов
Database / Redis 30–70 тыс. ₽ Объём данных и нагрузка
Storage + Backup 30–80 тыс. ₽ Количество медиа
CDN / трафик 70–200 тыс. ₽ Количество просмотров
Monitoring / Security 10–30 тыс. ₽ Количество сервисов
ИТОГО ≈ 200–500 тыс. ₽ Умеренная нагрузка

Цифры являются ориентиром для финансовой модели, а не коммерческим предложением поставщика.
